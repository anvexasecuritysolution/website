# LinkedIn banner artwork

Created with the built-in image-generation/editing tool using the user-supplied logo.
Final asset: anvexa-linkedin-banner.png.

Prompt: Use the supplied actual globe, A-orbit and ANVEXA Security Solutions logo on a near-black navy background. Place the headline "Find Risks. Guide Fixes. Verify Results." beside it, with "Web Applications | APIs | Servers | Networks" below. Use cyan network detail and a restrained shield. Leave space on the left for LinkedIn's profile overlay. No purple, contact details or unsupported badges. Keep text legible and the logo recognisable.

The generated artwork is 1983 x 793 pixels; it is a design preview, not an exact-sized company cover export. LinkedIn's current help page specifies 1512 x 256 for a company cover. The image tool did not honour the requested shallow aspect ratio. Do not stretch this preview to that ratio; a final re-layout/export is required to preserve the logo and text.
